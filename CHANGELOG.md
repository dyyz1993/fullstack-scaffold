# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-01

### Added

- CLI tool for creating BioMimic apps
- Full-stack React + Hono + TypeScript template
- Single-port development with Vite + Hono
- Hono RPC for end-to-end type safety
- Module-based backend architecture
- WebSocket + SSE real-time support
- Drizzle ORM with SQLite/MySQL/D1 support
- Zustand state management
- Ant Design UI components
- Module generator script (`npm run create:module`)
- Custom ESLint rules (34 rules) for code quality
- Validation scripts (13 validators)
- Vitest unit + integration tests
- Playwright E2E tests
- Pre-commit hooks with Husky
- Cloudflare Workers deployment support
- Multi-tenant platform support
- AI Agent module integration
- Monaco Editor for code editing
